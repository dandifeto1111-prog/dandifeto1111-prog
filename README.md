### 🚀 Proyecto Destacado — [AuraOS](https://github.com/dandifeto1111-prog/AuraOS)

> **El núcleo y compatibilidad de juegos de Windows 11 + un entorno completo escrito en Rust puro (Direct2D / DirectComposition).**

- **Shell completo (`AuraShell`)**: Barra superior, Dock inteligente con muesquita, Overview Bento (`PC` / `Dev & AI` / `Gamer` / `Fondos`), Launchpad, Centro de Control y widgets flotantes con controles semáforo unificados.
- **Reemplazo nativo de Configuración (`AuraSettings`)**: Planes de energía (`powercfg`), cambio real de Hz, mezclador de audio por app, Wi-Fi/Bluetooth/DNS y gestor de inicio en ~15 MB de RAM.
- **Pantalla de Bloqueo GPU (`AuraLock`)**: Reloj estilo Sonoma, fondos personalizados (imagen, video o Workshop) y desbloqueo por PIN cifrado o contraseña real de Windows.
- **Suite Nativa**: `AuraFiles` (con analizador de disco tipo WinDirStat), `AuraPhotos`, `AuraPlayer` y `AuraNotes`.
